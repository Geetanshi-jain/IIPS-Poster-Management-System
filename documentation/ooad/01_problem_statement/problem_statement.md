# Problem Statement

Currently, academic departments and event organizers rely on manual spreadsheets, paper evaluation forms, and scattered emails to manage academic poster presentations. This leads to tedious data entry, lost evaluations, bias in calculating averages, and significant delays in publishing results.

The proposed **IIPS Poster Management System** is a centralized web application designed to digitize the entire lifecycle of a poster presentation event. It allows administrators to create events with custom evaluation criteria, students to register and submit posters, and reviewers to grade posters dynamically on a unified dashboard. Finally, an automated algorithm computes averages and handles tie-breaking to instantly generate an objective leaderboard, significantly enhancing transparency and reducing administrative overhead.
