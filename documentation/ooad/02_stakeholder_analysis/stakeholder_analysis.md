# Stakeholder Analysis

## 1. Administrators
* **Role**: Event organizers and system managers.
* **Responsibilities**: Create events, define dynamic evaluation criteria, manage user accounts, assign reviewers to posters (individually or in bulk), and calculate final rankings.
* **Expectations**: A reliable dashboard to monitor all activities, simple assignment tools, and immediate automated result calculations.

## 2. Reviewers / Faculty
* **Role**: Evaluators of the submitted posters.
* **Responsibilities**: Log in, view assigned posters, enter objective scores for each dynamic criterion (e.g., Design, Content, Originality), and provide qualitative feedback.
* **Expectations**: An intuitive interface that clearly lists pending evaluations and provides an easy-to-use grading modal.

## 3. Students / Participants
* **Role**: The core participants submitting their academic work.
* **Responsibilities**: Register for the system, enroll in events, add co-authors, and submit their poster abstracts/details.
* **Expectations**: A seamless registration process and visibility into their poster status.
